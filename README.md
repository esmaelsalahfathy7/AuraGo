# 🚀 Neon Travel - Modern Landing Page

تصميم وبرمجة واجهة مستخدم (Landing Page) لوكالة سفر عصرية تعتمد على ستايل النيون والـ Dark Mode.

## 📌 عن المشروع (About)
هذا المشروع هو تطبيق عملي لتحويل تصميم عالي الجودة (UI Concept) إلى موقع ويب متكامل ومتجاوب (Responsive). يركز المشروع على استخدام تقنيات الـ CSS الحديثة لعمل تأثيرات الإضاءة والـ Glassmorphism.

## 🛠 التقنيات المستخدمة (Tech Stack)
* **HTML5:** للهيكلة الأساسية.
* **CSS3:** استخدام (Flexbox, Grid, CSS Variables).
* **JavaScript:** لإضافة بعض الحركات التفاعلية (اختياري).
* **Google Fonts:** خط (Inter / Montserrat).

## 🎨 مصدر الإلهام (Credits)
* **Design Concept:** مستوحى من تصميم **NeonTravel** التجريبي.
* **Images:** صور عالية الجودة من Unsplash و Pexels.

## 🚀 كيفية التشغيل (How to run)
1. قم بتحميل المشروع (Clone).
2. افتح ملف `index.html` في أي متصفح .
3. او من خلال الرابط التالي ( https://esmaelsalahfathy7.github.io/AuraGo/ )
